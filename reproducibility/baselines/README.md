# Baselines

Third-party repositories are not vendored. Each directory pins an upstream
commit and provides the applicable subset of `upstream.patch`, `configs/`,
`scripts/`, `UPSTREAM_LICENSE`, and a `README.md` with checkout, patch, and run
commands.

| Method | Code directory |
|---|---|
| EverMemOS | [`evermemos/`](evermemos/) |
| Mem0 | [`mem0/`](mem0/) |
| LightMem | [`lightmem/`](lightmem/) |
| MemoryOS | [`memoryos/`](memoryos/) |
| MemPalace | [`mempalace/`](mempalace/) |
| Zep Local | [`zep_local/`](zep_local/) |

Local endpoint URLs are defaults only. API keys are read from environment
variables.
